Open File Bridge Connector

The connector lets model code running in Open WebUI's sandbox use the Open File Bridge app on this machine. It only ever talks to http://127.0.0.1:8765 — nothing else.

Bridge token

Paste the token shown by the Open File Bridge settings page (the same value you would otherwise put in the skill). It is stored in this browser only (chrome.storage.local) and attached automatically — model code never sees it.

Connection test

Checks that the bridge is running and the token is accepted.
