Open File Bridge — recovery guide

Version-matched to extension … (the desktop app's recovery-guide.html equivalents, extension mode).

“permission needed” error

The browser requires the user to re-confirm folder access after a restart or when the grant expires.

Click the Open File Bridge toolbar icon.
Press Reconnect — the folder is NOT re-picked; permission is re-asked on the stored handle.
On the browser's permission bubble choose “Allow on every visit” — that choice is persistent and you will not be asked again on future restarts. (“Allow this time” works too but asks again after the next browser restart.)

“engine tab closed” / engine_needed error

PDF text extraction, PDF operations and OCR run in a background tab of the extension itself — not on any server.

Click the Open File Bridge toolbar icon.
Open the engine tab and keep it open while the assistant works with PDFs or scanned files.

“no shared folder configured”

Click the toolbar icon (it opens the settings page) and choose a folder with Choose folder…. Files outside that folder are never accessible.

Writes refused (403)

The folder may be read-only, or writes were disabled for it in the extension's options page. Either re-pick the folder with write access or enable writes in settings.

Legacy formats (.doc, .xls)

Open the file in your office app (Word / Excel / LibreOffice) and save it as .docx / .xlsx — then the assistant can read and edit it.
