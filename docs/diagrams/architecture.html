How Open File Bridge works

The Open WebUI model describes an operation, Pyodide runs the bridge client in the user's tab, and the extension applies policy before using browser-granted file access.

Why it works

The extension avoids the browser's public-site-to-loopback restriction. File operations stay inside browser extension APIs.

Trust boundaries

The server supplies instructions; the browser runs them; the extension independently validates the sender and operation.

Deployment shape

One shared Open WebUI skill, one extension per user, and only folders each user explicitly grants.
