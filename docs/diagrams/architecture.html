Open File Bridge — Architecture

model-guided local file access · file bytes never leave the user's machine

Why it works

  • • Open WebUI's Code Interpreter is Pyodide — WebAssembly Python running in the user's browser
  • • Browser-side Python can reach the user's own localhost
  • • The bridge listens there; no tunnels, no MCP servers, no per-user infra

Trust boundaries

  • • Server: hosts chat + skill text only
  • • Browser: executes model code, sandboxed (Origin: null → token auth)
  • • Machine: bridge guards ONE folder; everything else refused

Deployment shape

  • • One central Open WebUI, any number of users
  • • Each user runs the bridge app locally (binary or Python)
  • • Works for 10 or 10,000 users with zero server file I/O

Open File Bridge · verified on Open WebUI v0.11.1 · Apache-2.0
