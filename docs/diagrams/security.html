Defense in depth · extension 3.x

Every request crosses five security layers

Model-generated code is untrusted. Browser permission, sender identity, transport policy, filesystem scope, and recovery rules each fail closed before a local operation succeeds.

Threat model

Neither model output nor page JavaScript is trusted to define its own access. Authority comes from browser and extension state.

Fail closed

No configured site, no folder permission, an invalid envelope, or an out-of-scope path stops the operation.

Recovery

Overwrites preserve a version, deletes move to trash for 30 days, and the audit log records extension activity.
