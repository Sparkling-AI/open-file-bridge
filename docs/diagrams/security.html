Open File Bridge — Security Model

defense in depth · a request must pass every layer before touching a file

Threat model

  • • Model-generated code is UNTRUSTED — the sandboxed Pyodide iframe (Origin: null) is treated like a foreign origin
  • • A prompt-injected model can at worst reach the loopback listener with a guessed token — and then faces L2–L4
  • • The server is never a file path; exfiltration to it has no route

Recoverability

  • • Every overwrite snapshots the prior version (versions/)
  • • Deletes are trash-moves (trash/), purge is 403 by design
  • • audit.log (JSONL) records every file-touching call, secrets scrubbed

Fail-closed defaults

  • • Fresh bridge = UNLOCKED = all file endpoints 503 until an admin configures tier 1 or tier 2
  • • Read-only mode available as a deployment stance
  • • Signing/SmartScreen guidance: docs/SUPPORT.md
